## 1. 시험장에서의 흐름 (이 순서로만 하면 된다)
1. `exam_template.cpp` 전체 복사 -> 빌드되는지 먼저 확인 (회전하는 상자가 뜨면 성공)
2. 문제를 읽고 **명령어 목록**부터 표로 정리: `키 -> 어떤 변수가 바뀌는지`
3. 그 변수들을 `[1] 상태 변수`에 선언, `reset_state`에 초기값
4. `[3] drawScene`에서 **정적인 장면부터** 그림 (바닥 -> 물체). 움직임은 나중에
5. `[4] key_callback`에서 변수만 바꾸게 연결 -> 한 키씩 확인
6. 시간에 따라 변하는 건 `[2] update`로 (`값 += 속도 * dt`)
7. 시간이 부족하면 **되는 것만 완성**. 막힌 기능은 주석 처리하고 넘어가기

핵심 원칙: **키보드는 변수만 바꾸고, 그리기는 변수를 읽어서 그린다.** 이 구조만 지키면 대부분의 문제가 풀린다.

## 2. 반드시 손에 익힐 5가지
| 주제 | 외울 것 |
|---|---|
| 행렬 순서 | `부모 * 이동 * 회전 * 크기` (오른쪽부터 적용). 자식은 부모 행렬을 곱해서 그림 |
| 카메라 | `lookAt(eye, target, up)` + `perspective(fov, aspect, near, far)` / `ortho(l,r,b,t,n,f)` |
| 관절 회전 | 관절 위치로 `translate` -> `rotate` -> 물체는 관절 기준으로 아래/앞에 그림 |
| 입력 | `press`(토글) vs 꾹 누르기(이동). 소문자/대문자 구분은 `ch` 변환 코드로 |
| 시간 | `update(dt)`에서 `x += speed*dt`, 왕복은 min/max 에서 방향 반전 |

## 3. 연습 순서 (시간 순서대로, 매번 템플릿에서 시작)
1. **템플릿만 보고** 20번(벨트+상자) 다시 짜기 -> 막히면 `1020_20.cpp` 보고 막힌 줄만 확인
2. 22번(뷰포트 3개): `set_viewport` 레시피를 외우기
3. 23번(로봇): 부모-자식 + 걷기 애니메이션 + 점프/충돌
4. 21번(공 튕기기): 구조체 배열, 벽/상자 충돌, 마우스 드래그
5. 24번: 1인칭 카메라, 상태 머신(`state 0/1/2`)
6. 마지막엔 **인터넷/AI 없이 90분 타이머**로 한 문제 통째로 연습

공부할 때 규칙: 코드를 읽기만 하지 말고, **파일을 닫고 빈 화면에서 직접 타이핑**한다. 에러 메시지를 스스로 읽고 고치는 연습이 시험에서 가장 중요하다.

## 4. 자주 나는 실수 체크리스트
- 물체가 안 보임 -> 컬링(면 방향), 카메라가 물체 안쪽, `near/far` 범위, 크기 0 확인
- 벽이 반대로 보임 -> `draw_plane` 면 방향표(템플릿 위쪽 주석) 확인
- 회전축이 이상함 -> 행렬 곱 순서(회전을 이동 앞/뒤에 둔 것이 맞는지)
- 키가 안 먹음 -> 대문자는 `ch == 'P'`로 비교, `+`는 `GLFW_KEY_EQUAL`
- 속도가 컴퓨터마다 다름 -> `dt` 안 곱함
- `P` 와 `p` 같이 shift 키: 템플릿의 `ch` 변환 코드 그대로 사용
- 컴파일 에러 폭탄 -> 첫 번째 에러부터 고치기 (나머지는 연쇄 에러인 경우가 많음)
